# @omacode/core

Small shared primitives for the Omacode plugins. This package contains no plugin and registers no hooks.

- `journal`: the append-only decision journal and its path.
- `heldout`: where a contract keeps its held-out cases.
- `jsonc`: comments in the JSON configuration files.
- `redact-config`: the `redact` settings block, defaults and parser.
- `secrets`: the `looksSecret` rule shared by the guard and the sandbox.
